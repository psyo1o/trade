1. **조기청산 비율이 높은 전략/시대** — 스윙 시간가중 하드·V8 매도선을 era별로 A/B (hold longer on winners).

4. **코인 vs 주식** — 보유 시간·조기청산 패턴 분리; 코인은 V8_TIME_STOP 유예 효과 별도 집계.
